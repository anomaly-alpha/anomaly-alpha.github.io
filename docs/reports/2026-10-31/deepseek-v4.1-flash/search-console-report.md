## Findings and recommendations

### P0 — Fix the redeem-page conversion gap

`/guide/redeem/` now attracts **3,419 page impressions** but only **89 clicks** (2.6% CTR) at position 7.9. Redeem-theme queries as a whole have 6,755 impressions at 14.3% CTR, versus 37.7% for codes-theme queries.

The redeem page's own top queries are navigational: `https://redeem.invincible.ubisoft.barcelona/` (300 impressions, 3.7% CTR, position 6.5), `redeem.invincible.ubisoft.barcelona` (186, 5.9%, 5.0), and `redeem invincible ubisoft barcelona` (153, 3.9%, 6.3). Separately, the high-volume code-redeem queries (`invincible gtg code redeem`, 1,112 impressions) are served by the code page at 14.5% CTR. For the portal-style queries, users likely want the official Ubisoft page, not a five-step explainer.

Actions:

- Retitle the page around the official portal intent, e.g. “Invincible GTG Redeem Portal — Official Ubisoft Link & Login Fixes”.
- Put the official Ubisoft Barcelona portal URL and a large “Open official portal” CTA above the fold, before the step-by-step content.
- Add a short “Why the portal says invalid code” troubleshooting block with the exact error strings users search for.
- Add FAQPage schema for the top redeem questions and link the code page to the redeem page with the anchor “Redeem codes”.
- Keep the step-by-step guide, but treat it as secondary content under the portal CTA.

**Directional impact:** moving `/guide/redeem/` from 2.6% to 6–8% CTR would add roughly **116–185 clicks/28d**. The theme-level upside is larger but bounded by navigational intent.

### P0 — Build an actual XP/rank-up calculator

The progression cluster has **384 impressions and 8 clicks (2.1% CTR)**. The zero-click set alone includes `invincible xp calculator` (40 impressions, position 3.0), `invincible gtg rank up chart` (35, 4.6), `invincible guarding the globe rank up guide` (44, 6.9), and `invincible gtg rank up guide` (54, 5.9). `/guide/xp/` ranks well but explicitly tells users it is “not an in-page calculator” and links out to a community tool.

Actions:

- Build a small in-page calculator on `/guide/xp/` (current level → target level, rarity, output Gold/Blue/Pink XP). A static HTML/JS tool is enough; no backend.
- Retitle to “Invincible GTG XP Calculator & Rank-Up Chart” and put the calculator above the reference tables.
- Add a rank-up requirements chart with exact tier thresholds, and keep the community link as a fallback.
- Internal-link the calculator from `/guide/code/`, `/guide/beginners/`, and `/guide/pvp/`.

**Directional impact:** roughly **30–55 clicks/28d** if the cluster moves from 2.1% to 10–15% CTR and the calculator earns links/mentions.

### P1 — Improve non-code page titles and snippets

The eight non-code guides plus the homepage produce **14,627 page impressions** but only **386 clicks** (2.6% CTR). Individually: `/guide/xp/` 3.2%, `/guide/redeem/` 2.6%, `/guide/pvp/` 3.0%, `/guide/beginners/` 2.0%, `/guide/event/` 1.8%, `/guide/creators/` 1.3%, `/guide/faq/` 1.0%, `/guide/login/` 0%, `/` 5.1%.

Actions:

- Put the concrete number/benefit in each title and meta description: “1,393 gems/week”, “500 gems per event cycle”, “all 14 league payouts”, “first-day roadmap”.
- Match the dominant query wording exactly (e.g. “rank up chart”, “wish event”, “login rewards”, “beginner guide”).
- Add a one-line “what you get” summary at the top of each guide so the snippet can surface it.
- Review `/guide/login/` (0 clicks, 243 impressions, position 6.2): either strengthen it with a login-rewards table or consolidate it into `/guide/beginners/` with a redirect.

**Directional impact:** lifting the non-code pages from 2.6% to 4–5% CTR would add roughly **199–345 clicks/28d**.

`invincible gtg wish event` has 96 impressions and 1 click at position 7.4; `wish event invincible gtg` adds 46 impressions and 0 clicks; `invincible guarding the globe freecash` has 30 impressions and 0 clicks. ## Methodology and caveats

- **API:** Search Console Search Analytics API, `type=web`, `dataState=all`, 25,000 rows per request with `startRow` pagination.
- **Dates:** UTC dates; data is available through **2026-10-29** (Oct 30–31 were not yet reported when pulled on Oct 31).
- **Auth:** Application Default Credentials from `gcloud auth application-default login`, scope `webmasters.readonly`, quota project `anomaly-alpha-gsc`.
- **Query anonymization:** the query dimension covers 67% of clicks and 47% of impressions; theme and query totals are lower bounds.
- **Page totals are not additive:** page-level impressions can exceed property-level impressions because GSC can attribute a result to multiple pages (sitelinks/aggregation). Use page rows for relative comparison only.
- **Average position** is impression-weighted; positions are averages and not directly comparable across queries with different impression mixes.
- **Forecasting:** no forecast is included; the daily series is volatile around game updates and events.
