How to redeem a promo code

1. Open your account settings

Launch Invincible Guarding the Globe and tap your level badge marked LVL in the top-left corner.

2. Generate a verification code

Find Verification Code in the account settings, generate a fresh code, and copy it. Generate a new one if the current code expires.

3. Open the Ubisoft portal

Open redeem.invincible.ubisoft.barcelona in your browser. This is the official external redemption website.

4. Submit both codes

Enter your verification code and the active promo code, then submit the redemption form.

5. Relaunch the game

Close and reopen the game. Successful rewards normally appear in a pop-up on the main screen.

Troubleshooting redemption errors

  • Verification code expired: return to the game and generate a fresh code immediately before submitting.
  • Invalid or expired promo code: check the active Invincible GTG code list and copy the code exactly.
  • Rewards missing: fully close and relaunch the game after a successful submission.
  • Wrong website: use the exact Ubisoft Barcelona address above and avoid unofficial lookalike domains.

Redemption questions

Where do I redeem Invincible GTG codes?

Redeem codes at the official Ubisoft Barcelona portal: redeem.invincible.ubisoft.barcelona.

How do I get a verification code?

Open Invincible Guarding the Globe, tap your LVL badge in the top-left corner, open account settings, and generate a verification code.

Why is my redemption code not working?

Generate a fresh verification code, check the promo code for typing errors, confirm the code is active, and relaunch the game after redemption.
