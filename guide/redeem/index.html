Official Ubisoft Barcelona portal

Open the Invincible GTG Redeem Portal

redeem.invincible.ubisoft.barcelona

Open the official portal →

External Ubisoft website · opens in a new tab · the only official redemption channel

Enter a fresh verification code from your game account to claim promo-code rewards such as gems, heroes, shards, and event items. Verification codes expire after just a few minutes, so open the portal first and generate the code second. Third-party sites that claim to redeem codes may not work or could compromise your account.

Troubleshooting redemption errors

  • Verification code expired: return to the game and generate a fresh code immediately before submitting — they are only valid for a few minutes.
  • Invalid or expired promo code: check the active Invincible GTG code list, copy the code exactly as shown, and verify it is still in the active list above.
  • Rewards missing after successful submission: fully close and relaunch the game. Successful rewards normally appear in a pop-up on the main screen within seconds of relaunch.
  • Wrong website or domain: use the exact Ubisoft Barcelona address above (redeem.invincible.ubisoft.barcelona) and avoid unofficial lookalike domains that may not process redemptions correctly.

Step-by-step: how to redeem a promo code

Only needed if you have never redeemed a code before.

1. Open your account settings

Launch Invincible Guarding the Globe and tap your level badge marked LVL in the top-left corner.

2. Generate a verification code

Find Verification Code in the account settings, generate a fresh code, and copy it. Generate a new one if the current code expires.

3. Open the Ubisoft portal

Open redeem.invincible.ubisoft.barcelona in your browser. This is the official external redemption website.

4. Submit both codes

Enter your verification code and the active promo code, then submit the redemption form.

5. Relaunch the game

Close and reopen the game. Successful rewards normally appear in a pop-up on the main screen.

Redemption questions

Where do I redeem Invincible GTG codes?

Redeem codes at the official Ubisoft Barcelona portal: redeem.invincible.ubisoft.barcelona.

How do I get a verification code?

Open Invincible Guarding the Globe, tap your LVL badge in the top-left corner, open account settings, and generate a verification code.

Why is my redemption code not working?

Generate a fresh verification code, check the promo code for typing errors, confirm the code is active, and relaunch the game after redemption.
